# Creator Store

Plataforma para afiliados e criadores de conteúdo criarem uma página pessoal com redes sociais, links e uma vitrine de produtos afiliados.

## Status

Em planejamento.

## Público inicial

- Afiliados do TikTok
- Afiliados do Instagram
- Criadores que recomendam produtos

## Objetivo do MVP

Permitir que um usuário:

- crie uma conta;
- configure uma página pública;
- adicione suas informações e redes sociais;
- cadastre produtos;
- publique links afiliados;
- compartilhe sua vitrine.
